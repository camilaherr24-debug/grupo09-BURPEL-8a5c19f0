# Proyecto Informático - UPSO

Aplicación web que usa la API que nos dio el profesor para mostrar un listado de tecnologías y lenguajes de programación.

## ¿Qué hace?
- Página de presentación al entrar
- Muestra todas las tecnologías con un buscador
- Muestra los lenguajes disponibles, también con buscador
- Trae la información directo de la API
- Se ve bien desde la compu y desde el celular

## Con qué lo hicimos
- HTML5 → armar la estructura de cada página
- CSS3 → darle diseño, colores y que se vea prolijo
- JavaScript → conectar con la API y mostrar los datos
- Git y GitHub → para ir guardando todo y compartirlo con el grupo
